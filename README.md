# PipaPost
Your own social-media scheduler: Instagram, Facebook Pages, YouTube, TikTok, LinkedIn.
- Web app: `index.html`, `app.js`, `styles.css`, `config.js` (static — deploy the repo root on Netlify, no build step).
- Backend: `supabase/functions/*` (Supabase edge functions), schema in Supabase migrations `pipapost_*`.
See SETUP.md.
